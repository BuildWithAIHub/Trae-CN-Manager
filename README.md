# Trae CN 管家 0.2.4

面向 **Windows 10 / 11 x64 的 TRAE CN 桌面账号与配置管理器**。集中管理多个官方登录账号、独立实例、积分签到、MCP、Skills 和 Rules，并提供加密迁移备份。

[下载最新安装包](https://github.com/BuildWithAIHub/Trae-CN-Manager/releases/latest) · [安装与分发](docs/INSTALL.md) · [操作说明](docs/INTERFACE.md) · [验证报告](docs/VERIFICATION-0.2.4.md)

这是独立实现的社区工具，与 TRAE 官方没有隶属关系。已核对的原生接口适配版本为 **TRAE CN 3.4.3 / 3.4.7**；识别到基线不代表每个账号都具备签到资格。真实短信登录、多个账号同时使用、积分领取和跨机器恢复仍需按[验收清单](docs/ACCEPTANCE.md)检查。

## 可以做什么

- 经授权定位各本地磁盘上的 TRAE 程序、资料、缓存与全局配置；支持手动输入和浏览、确认后不重复提示、原位置失效后重新查找。
- 检测已登录资料；创建独立资料目录，启动、切换或同时打开多个实例，编辑账号名称与备注。
- 手动签到、解锁后自动签到、可调整时间的 Windows 每日后台签到；默认北京时间 **09:00**。支持登录后补跑当天任务，同步官方签到状态，已签账号显示绿色标记并禁用按钮，批量结果区分成功与此前已签。
- 默认每 15 秒轮询官方积分、用量和会员权益，可在 5～300 秒之间调整；签到后立即刷新。失败保留上次结果并标明时间与失败状态。
- 分别管理官方默认实例、独立实例和项目 MCP；编辑、启停、合并导入、导出、显式连接检测。
- 管理共享的全局 Skills/Rules，以及项目自己的 Skills/Rules；支持技能内目录和文件编辑、单项及批量启停/删除、本地目录/Markdown/ZIP 和公开 HTTPS/GitHub 导入。
- Skill/Rule 用途支持单项或当前范围全部中英互译、进度取消与恢复原文。批量发送前会说明范围并再次确认，可使用 MyMemory 或自定义 LibreTranslate；密钥与译文缓存加密保存，翻译不改写原文件。详情见[安全说明](docs/SECURITY.md#可选在线翻译)。
- 自定义全局 Skills 存储目录，通过 Windows 目录联接让 TRAE 原生路径实际加载；支持冲突拒绝、复制校验、失败回滚和返回默认目录。
- 本机密码保险库、高熵恢复码、独立密码的加密迁移备份、配置修改备份、冲突跳过、日志、深浅主题、自定义标题栏、托盘与闲置锁定。
- 为所选账号保存加密记忆快照；打开实例时选择来源合并或直接打开，并提供记忆预览和历史回滚。

全局 Skills/Rules 按本项目约定在各账号间共享；实例 MCP 与项目配置分别管理。详细范围、参考项目和未实现能力见[功能覆盖表](docs/FEATURES.md)。

## 直接使用 EXE

1. **发给朋友或普通用户：只发送 TraeCNManager-0.2.4-Setup-x64.exe 这个安装包**，双击安装即可。它包含 Python、Qt 和所有管家依赖，安装位置可自选，无需管理员权限。不要单独发送便携目录中的 TraeCNManager.exe：该主程序需要同目录的 _internal。偏好免安装时，请发送并完整解压整个 Windows 便携 ZIP。TRAE 本体仍需另外安装。
2. 首次设置至少 **8 个字符**的本机解锁密码。程序默认将自己的数据保存在便携目录的 `data/`，登录页和设置页均可打开数据目录。请在设置中生成并另行保存恢复码；请勿把 `data/` 作为源码上传。
3. 解锁后在账号页的“添加账号”菜单点击“检测本机账号”。若尚未登录，先在官方 TRAE 窗口通过手机号完成短信等官方验证，再回到管理器，从“更多”菜单选择“同步登录”。
4. 添加其他账号时，创建独立实例，在对应窗口完成官方登录后同步。切换通过启动所选实例完成；首次多账号使用应核对每个窗口的官方账号信息。
5. 先尝试“查询用量”和一次手动签到，对照官方客户端显示。接口失败、未开放或登录失效都不会记为签到成功。
6. 需要关闭管理器后仍自动签到时，在设置中**明确启用“后台每日签到（任务计划 / 当前用户启动项）”并保存**。仅修改时间不会自动启用后台运行；保存后查看“当前后台方式”及诊断结果。

MCP/Skill 可能需要自己的 Node.js、NPX、UVX、Git 或其他依赖。便携 EXE 附带的是本管理器运行环境，不包含所有第三方工具。

### 定位安装与数据

首次解锁先快速核验手动位置、已确认路径、正在运行的官方程序、快捷方式及常见目录。找到后只需确认一次，无需全盘扫描；找不到时可直接手动定位。只有明确选择深度扫描并同意读取磁盘目录后才执行全盘扫描。确认位置提示与扫描授权分别保存，相同结果不反复提醒。

扫描可取消，最多约 **120 秒 / 20 万个目录**；跳过系统保护目录、目录链接等，并记录访问被拒绝、取消和达到上限等部分完成状态。它不是取得全盘权限或找到所有内容的保证。扫描不完整、没有发现程序或权限不足时，可手动指定程序 `.exe`、用户数据根目录、全局配置目录和缓存位置；这些目录无需位于 C 盘。程序路径可从桌面 TRAE 快捷方式右键“属性”中的“目标”快速取得；用户数据根目录通常包含 `User/globalStorage/storage.json`，全局目录通常为用户主目录下 `.trae-cn`。设置页提供完整定位指南。

### 升级已有便携版本

退出旧版 GUI 与后台进程后更新程序及依赖文件，**保留桌面原便携目录的 `data/`**。0.2.4 继续使用原保险库和原解锁密码，不会为旧库预先生成恢复码；先正常解锁，再从设置中生成恢复码。若同时搬迁便携目录，按下文说明重新注册后台运行路径。

## 后台签到和密码

默认不创建后台计划任务或专用后台启动项。启用后，程序为当前 Windows 用户保存一份 **DPAPI 保护的后台解密材料**，优先注册每日时间与登录触发任务，并设置 `StartWhenAvailable`。如果 Windows 拒绝创建计划任务，则自动降级为 **HKCU 当前用户登录启动项 + 隐藏的独立后台进程**；设置与诊断会显示实际方式 `task` 或 `startup`，不会把降级误报为计划任务创建成功。

降级进程使用 `--background` 运行，**关闭或退出管理器 GUI 后仍继续运行**。它每 30 秒读取计划设置，达到计划时间后尝试签到，普通失败的重试间隔为 15 分钟，同日成功账号跳过。保存关闭后台开关后，空闲进程会在下一次检查（约 30 秒内）退出；若恰有操作进行，则等待该次操作结束。关机时进程停止，下次登录 Windows 后由启动项重新启动并尝试补跑当天签到。

两种方式都在当前 Windows 用户会话中运行，**不必每次输入管理器密码**；管理器界面仍要求正常解锁。登录触发/后台进程首次运行也会尝试当天签到，可能早于所设每日时间。

这是你主动选择的便利模式：掌握当前 Windows 用户会话或其系统密钥的程序，可能获得相同的本机解密能力。关闭后台签到会删除本工具的任务、专用后台启动项与后台密钥文件；“登录 Windows 时启动管家”是单独的 GUI 启动设置。详见[安全说明](docs/SECURITY.md)。

电脑关机、未登录或没有网络时无法保证执行。重新开机并登录后尝试的是**当天签到**，不能追领已经过去日期的奖励；是否有积分、优惠券或资格由官方决定。

已生成恢复码时，可在登录页点击“忘记密码”，用完整恢复码重设本机密码。恢复码包含高熵私钥，只在生成时展示；管理器保存公钥和加密恢复封装，不能再次显示原恢复码或查出原密码。生成新码会使旧码失效，修改密码则同步更新恢复封装与已启用的 DPAPI 后台材料。密码更新采用带日志的文件组提交；失败时恢复原组，重启时处理未完成的更新。

旧库必须先用原密码正常解锁才能建立恢复码。**原密码和恢复码都遗失时，软件不能绕过旧密码**；可尝试使用密码仍已知的加密迁移备份，在新的保险库导入。打开数据目录只帮助定位文件，不等于能读取其中的加密账号。恢复码与迁移密码应分别妥善保存，详见[安全说明](docs/SECURITY.md)。

## 配置、迁移和更新

在 MCP/Skills/Rules 页面选择作用域后再编辑；删除或停用会保留恢复备份，可在备份页查看本机配置变更历史并回滚。MCP 保存保留未知字段，但 JSONC 注释与原排版会转为标准 JSON。连接检测会实际启动该 MCP 的命令或访问其服务，仅在你点击检测后发生。

GitHub 技能导入接受仓库首页、archive ZIP 或 `https://github.com/owner/repo/tree/main/path/to/skill`。指定子目录时只安装该子目录内的技能，不把仓库里的其他技能一起安装；带斜杠的分支名最多尝试 6 个边界，特殊深层链接无法解析时可改用明确的 ZIP。

MCP 也支持本地 JSON/JSONC、文件夹中的常见配置文件搜索、公开 HTTPS/raw 配置文件和携带完整配置的 `trae-cn://…/mcp-import` 链接；单个服务器对象需要名称。HTTPS 的 MCP 服务流地址不等同于配置文件下载链接。Skill 的单独 Markdown 导入只保存主文件，引用脚本和其他资源需另行提供；完整技能优先使用目录或 ZIP。导入不执行脚本；精细启停和删除均有备份及冲突检查，批量中途失败会尝试恢复本次变更。

全局 Skills 自定义目录不是只修改管理器指针：迁移后原生 `global_home/skills` 指向实际存储目录，TRAE 仍从原生入口加载。已有同名文件拒绝覆盖，失败会回滚；返回默认目录会复制内容并解除本工具创建的联接，保留原自定义目录。项目 Skills 继续在各项目管理。编辑或迁移前请关闭受影响的 TRAE 窗口，避免与其同时写入。

### 积分刷新与记忆同步

积分是官方接口轮询结果，涵盖接口返回的购买套餐权益、奖励等信息；缺失字段显示未知。它**不是服务器推送，不保证消费瞬间零延迟**，还受网络和服务刷新速度影响。可暂停自动刷新或手动查询；查看上次成功时间与失败状态后再判断余额是否最新。

[TRAE 官方记忆文档](https://docs.trae.cn/ide_memories)说明记忆保存在本机用户目录。管理器按实际全局目录读取 `memory/user_profile.md` 及 `memory/projects/<项目标识>/project_memory.md`；这些原生文件在同一用户的 TRAE 窗口间共享，并非天然按账号隔离。先将当前共享记忆保存为某个账号的加密快照，再在打开实例时选择来源，预览后合并；也可选择“不同步，直接打开”。**合并会影响本机共享记忆，其他已打开窗口也可能看到**。合并前状态保存在加密历史中，可精确回滚；回滚可能移除该历史之后新增的受管记忆，应先核对预览并关闭相关窗口。

迁移请使用“导出加密迁移备份”，为该文件设置独立密码。备份包含账号、受管配置、当前原生记忆及已保存的账号记忆快照；新电脑导入时合并账号，遇到已存在的同一 TRAE 用户会保留本机条目。配置另行恢复，已有文件跳过，项目配置需要显式选择本机对应目录；导入的原生记忆需用户确认合并，不会静默覆盖本机记忆。跨设备后官方登录可能需要重新验证。普通 MCP JSON 与 Skill ZIP 导出不是加密迁移包，含凭据的完整导出只适合私下保存。

在设置填写你自己发布的 `owner/repository` 后，可检查该仓库的 GitHub 最新 Release 并打开发布页。程序不自动替换自身，不承诺 TRAE 升级后自动适配；需要更新适配器并发布管理器新版本。未来版本与实际检测说明见[兼容性文档](docs/COMPATIBILITY.md)。

搬迁便携目录前，先在原目录关闭后台任务和登录自启动；搬迁后从新位置重新启用，避免 Windows 仍记录旧的程序路径。

## 从源码运行和构建

在 Windows x64、Python **3.11** 环境中，在仓库根目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements-dev.txt
python -m pytest
python scripts/build.py
python scripts/build_installer.py
```

源码运行：

```powershell
python main.py
```

隔离的内置自检使用临时目录和合成数据，不访问真实账号：

```powershell
python main.py --self-test
# 便携版本也支持：
.\TraeCNManager.exe --self-test
```

`--data-dir <目录>` 可指定独立管理器数据目录。开发或验收时请用空白测试目录，避免与日常保险库混用。源码测试中的网络和多账号场景以模拟接口为主，不能代替真实服务验收。
