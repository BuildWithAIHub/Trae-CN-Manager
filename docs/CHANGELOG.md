# 更新记录

## 0.2.4 — 2026-10-24

- Skills 增加“全部翻译”：将当前配置范围内的用途说明译为中文或英文，支持进度、取消、重复内容复用与恢复原文。批量发送前再次确认范围；达到服务额度会保留已完成结果。
- 继续提供可单独分发的完整安装包、便携 ZIP 和源码。发布内容使用独立目录检查，排除个人账号、配置、缓存、密钥、备份和开发日志。
- 新增干净安装与 GitHub 发布说明。清空本机管家数据是单独的本机操作，不会触碰官方 TRAE 的账号或原生配置。

## 0.2.3 — 2026-10-24

- 账号页增加 Ctrl/Shift 多选提示和独立签到状态。官方确认当天已签后显示绿色“✓ 今日已签到”，禁用相应入口；同步 TRAE 内的签到结果，批量结果区分本次成功、此前已签和失败，跨天重新确认。
- Skills/Rules 用途旁增加中英互译及恢复原文。首次在线翻译需同意；只发送所选的一句用途，译文与密钥加密保存，切换服务重新授权，撤销授权后不再请求。
- 安装器调整 DPI、字体与留白，统一管理器、安装程序、任务栏和快捷方式的图标。保留原位升级、独立安装包和便携分发方式。

## 0.2.2 — 2026-10-24

- 账号与 MCP 页面统一为搜索、状态筛选、添加及更多菜单；选中后显示常用操作，批量和记忆操作收进菜单。无选择时不自动作用于全部，刷新积分时保留搜索和筛选状态。
- Skills、Rules 改为一句简短用途说明，Markdown 格式和冗长触发条件不再铺满列表；没有描述的规则从正文提取，原文保留。说明会随新建、导入与刷新更新。
- 所有应用内弹窗统一自定义主题标题栏，涵盖新建/编辑、密码、文件选择、确认和提示窗口；深浅主题一致，保留拖动、关闭、Esc 和默认按钮行为。
- 完整安装包采用一致的界面风格；保留便携包、源码和原账号数据的升级方式。

## 0.2.1 — 2026-10-24

- 增加可单独传给朋友的完整 Setup EXE，内嵌运行依赖、安装前哈希校验和失败回滚，可自选盘符，升级保留 data；保留完整便携 ZIP 供免安装使用。GitHub Actions 同时构建并验收两种分发方式。
- Skills/Rules 精简为搜索、状态筛选、新建、导入和更多；显示条目计数，选中后展示详情和编辑动作。批量管理收进菜单，未选择时不再默认全部删除，全部删除需明确确认。
- 位置检测优先核验运行中的官方程序、已确认位置、快捷方式和已知目录；首次快速定位成功后无需执行全盘扫描。修正旧版把临时测试资料和备份程序混入结果的问题，提供明显的手动定位入口与快速指南。
- 对本机账号接口、实际配置管理和原生加载做实机验收；通过、失败和证据范围以随版本交付的实测报告为准。

## 0.2.0 — 2026-10-24

- 授权后跨盘定位 TRAE 程序、用户数据、缓存和全局目录；支持手动输入/浏览、快速定位指南、状态确认后不再重复提醒，以及旧路径失效后的重新查找。扫描可取消，默认限制约 120 秒/20 万目录，明确报告权限不足或部分完成。
- Skills 增加目录/文件树、文本编辑、新建、资源启停和删除；Skills/Rules/MCP 支持批量操作及失败回滚。增加 MCP 文件夹搜索、公开 HTTPS/raw 和原生配置链接导入，以及本地/HTTPS Markdown、HTTPS ZIP 技能导入。单 Markdown 只含主文件，不自动获取脚本资源。
- 全局 Skills 可自定义实际存储目录，使用原生 Windows junction 加载；迁移前备份、复制校验、冲突不覆盖、失败恢复和返回默认，旧自定义目标保留。
- 积分与官方权益默认 15 秒轮询，可调 5～300 秒或关闭；签到后立即刷新，失败保留上次成功值并显示时间。此功能不是服务端推送，不承诺消费瞬间更新，也不推算官方未返回的套餐数据。
- 新增高熵恢复码、登录页重设密码和打开数据目录。只保存恢复公钥和加密封装，恢复私钥只生成时展示。密码更新预计算保险库/恢复/DPAPI 文件组，失败回滚，重启恢复未完成的 journal。
- 新增主题一致的自定义标题栏、拖动、双击最大化及窗口按钮。
- 新增账号加密记忆快照、打开实例时选择来源/不同步、合并预览与精确历史回滚。实际写入本机共享的原生 memory，其他已打开窗口可能读取；加密迁移包含当前原生记忆和已保存快照，导入原生记忆需再次确认合并。

旧版便携升级请保留原 data，继续使用原解锁密码；不会为旧库预生成恢复码。先正常解锁，再生成恢复码。原密码遗失且事前没有恢复码时，无法绕过旧密码。

TRAE CN 原生适配基线仍为 3.4.3，后续版本需重新核对并更新适配器；本次更新不宣称自动适配所有未来版本。真实全盘扫描、重启、所有付费套餐及真实记忆写入的执行结果以交付自检报告和用户验收为准，测试数量不在本文件预填。
