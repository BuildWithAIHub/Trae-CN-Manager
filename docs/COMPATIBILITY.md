# 0.2.4 TRAE CN 兼容性

文档更新日期：2026-10-24。原生适配核对日期：2026-10-24。目标系统为 Windows 10 / 11 x64，开发环境为 Python 3.11；完整 Setup EXE 与便携 ZIP 附带管理器依赖，不要求用户安装 Python。便携目录中的主程序不能脱离 _internal 单独分发。0.2.1 不把尚未实测的 TRAE 新版本自动列为兼容。

## 当前适配范围

原生登录容器、存储路径与接口标记以本机检查到的 **TRAE CN 3.4.3 / 3.4.7、VS Code 内核 1.107.1** 为基线。相关实现集中在 `trae_manager/trae.py`，系统任务在 `platforms.py`，路径定位在 `locations.py`，本地资源在 `configs.py` / `config_extra.py`，记忆在 `memory.py`。

诊断区分：

| 标记 | 含义 | 不代表什么 |
| --- | --- | --- |
| baseline | 识别到已核对的 3.4.3 / 3.4.7 产品及当前预期的原生接口/存储结构标记 | 不代表已替所有账号验证登录、签到资格、领取奖励或跨机器有效性 |
| unverified | 版本或标记不同，或无法完成结构识别 | 不自动判定完全不可用，也不宣称无需修改即可兼容 |

TRAE 使用私有实现和服务接口，这不是官方承诺长期稳定的 SDK。官方升级后应先诊断、查询和人工核对，再执行写入或领取。新增兼容版本需要维护者更新适配器、测试并发布新的管理器版本；GitHub Release 检查不提供自动适配。

## 配置位置

| 内容 | 默认位置 | 本工具策略 |
| --- | --- | --- |
| 官方默认实例 MCP | `%APPDATA%\Trae CN\User\mcp.json` | 单独作用域；解析真实目标，避免把 Junction 当成两份数据 |
| 独立实例 MCP | `<实例资料目录>\User\mcp.json` | 随所选实例分别管理 |
| 项目 MCP | `<项目>\.trae\mcp.json` | 分项目；官方项目 MCP 功能需启用并信任该项目 |
| 全局 Skills | `%USERPROFILE%\.trae-cn\skills` | 各账号共享 |
| 自定义全局 Skills | 用户选定的实际目录 | 原生 skills 入口使用本工具创建的 Windows junction；不是仅管理器可见的路径设置 |
| 项目 Skills | `<项目>\.trae\skills` | 仅所选项目 |
| 全局 Rules | `%USERPROFILE%\.trae-cn\user_rules` | 各账号共享；空/不存在目录不是故障 |
| 项目 Rules | `<项目>\.trae\rules` | 支持至多 3 层子目录 |
| 全局记忆 | `<实际全局目录>\memory\user_profile.md` | 本机同用户 TRAE 窗口共享 |
| 项目记忆 | `<实际全局目录>\memory\projects\<项目标识>\project_memory.md` | 原生项目标识及作用域按 TRAE 维护，不等于账号独立目录 |

这些位置与[官方 MCP 文档](https://docs.trae.cn/ide_add-mcp-servers)、[Skills 文档](https://docs.trae.cn/ide_skills)、[Rules 文档](https://docs.trae.cn/ide_rules)、[记忆文档](https://docs.trae.cn/ide_memories)及基线程序资源相互核对。官方记忆文档在 2026-10-24 核对了本地用户/项目记忆路径和不可自动跨电脑共享的范围；它不证明本管理器已在所有基线与后续版本上完成真实写入验收。官方文档可能随新版本变化，不能凭最新网页推定旧版本所有能力均已支持。

程序、用户数据、全局目录与缓存均可在设置页手动输入或浏览，支持非 C 盘。默认先快速检查已确认路径、运行程序和系统登记信息；找到后无需全盘扫描。主动进行跨盘深度扫描需要明确授权；确认位置提示不代表授予扫描权限。旧位置失效先快速重找，深度扫描由用户主动触发；确认过的相同状态不重复提醒，位置/访问状态变化后重新提示。扫描最多约 120 秒/20 万目录，可取消，跳过保护区、链接和无权限目录。达到限制、取消或拒绝访问时显示部分完成，不能当作完整全盘结果；找不到时应按设置页指南指定实际路径，不自动提升管理员权限。

`--user-data-dir` 与 `--extensions-dir` 的参数处理可在基线程序资源中确认，实例锁和 Electron userData 使用对应资料目录。此证据支持独立实例启动设计，但完整登录隔离和网页登录回调仍必须用多个真实账号验收。仅 `--user-data-dir` 不隔离用户目录下的全局 Skills/Rules，正好对应本项目已确认的共享设计。

## 启停与保存语义

基线全局 MCP 支持 disabled 字段，但项目 MCP 的启停状态另有本地存储。本工具不直接修改项目状态数据库：停用时把条目移出活动 `mcpServers`，存于同文件 `_trae_manager.disabledMcpServers`；启用时迁回。不要手动把同名条目同时放入两个映射。

Skills/Rules 停用时移到同级 `.trae-manager-disabled-skills` / `.trae-manager-disabled-rules`。这两个目录是本管理器约定，不是官方 TRAE 标准。目标目录有同名项时拒绝覆盖。

技能内文件/子目录停用使用原生技能树之外的 `.trae-manager-disabled-skill-entries/<技能>/…`；直接停用 SKILL.md 等同于停用整个技能。编辑已停用条目保留原作用域和状态。目录和批量操作有归属、链接、冲突与回滚检查；不能保证外部程序同时写入时仍具有跨进程原子性。

全局 Skills 自定义存储要求可创建目录及 Windows junction 的文件系统/权限。迁移先备份、校验复制且拒绝同名文件覆盖，再用原生入口指向实际目录；失败恢复原入口。返回默认目录会复制回原生位置，保留旧自定义目录。非本工具创建的既有联接不接管；项目 Skills 不自动迁移。实际 TRAE 是否加载变更需要重启目标窗口核对，磁盘离线或外部删除目录会影响加载。

MCP 可从 JSON/JSONC、常见配置文件夹搜索、公开 HTTPS/raw 和携带完整配置的 trae-cn/trae mcp-import 链接合并导入；不把只含官网跳转的链接当成完整配置。单个服务器对象需名称；私库认证不支持。Skills 另支持公开 HTTPS ZIP/Markdown，本地单 Markdown 只导入主文件，资源不会自动补齐。读取/导入不执行 MCP 或技能脚本。

JSONC 支持注释和末尾逗号，保存时改为 UTF-8 标准 JSON。MCP Server 未知字段与根对象未知字段保留；不承诺保留注释、空格或字段排版。MCP 连接测试实现基本 stdio JSON 行、Streamable HTTP 和旧 SSE 握手，不覆盖完整协议功能、所有身份授权流程或所有服务器扩展。

## 签到与权益

[官方更新日志](https://docs.trae.cn/ide_changelog)记载 2026-10-15 的 v3.4.1～3.4.4 加入签到活动入口。该说明支持存在每日活动，**不构成所有账号始终能领取积分的保证**。

本实现使用基线原生接口先检查、领取、再复查；权益查询只展示官方能够完整返回并计算的数据。接口变化、资格未开放、账号过期、设备验证或网络异常应显示失败/未知，而不是写入虚构成功。最终真实只读/领取检查结果由交付检查报告记录，不能用模拟响应替代。

0.2.4 在权益刷新时同时只读查询官方签到状态，包括在 TRAE 中完成的签到；官方确认当天已签后显示绿色标记并禁用对应入口。查询失败保留当天已确认的结果，跨北京时间日期后重新确认；批量结果区分本次成功、此前已签和未完成。

0.2.0 默认每 15 秒轮询权益，可调 5～300 秒或关闭，签到后立即查询；网络/认证失败保留上次成功值并显示时间及失败。套餐、Pro/Plus 等购买权益和签到奖励以官方实际返回字段为准；不是账单系统或服务端推送，不能保证每次消费后零延迟，也不能推算接口没有返回的数据。

后台运行依赖 Windows 当前用户 DPAPI 和有效登录状态。优先使用任务计划服务，按北京时间注册每日触发、登录触发及 StartWhenAvailable；若注册失败，自动降级为 HKCU 当前用户专用登录启动项与隐藏的独立 `--background` 进程。设置/诊断显示实际注册方式，不要求用户为计划任务申请管理员权限。

计划任务注册、降级启动项、实际账号查询和签到的本次结果，以独立交付检查报告为准。没有将关机重启、新手机号多账号登录、所有付费套餐或全天消费追踪预先标记为通过；个人余额不写入公开文档。

降级进程在 GUI 完全退出后继续运行，每 30 秒读计划时间与启用状态，普通失败的重试间隔 15 分钟，同日成功跳过。取消后台开关后空闲进程在下一轮检查退出；进行中的操作先完成。关机/未登录 Windows 不能执行，下次登录后重新启动并补跑当天，不能追领过往日期。跨机器迁移不迁移 DPAPI 后台密钥，需要在新机器自行启用。

## 密码、记忆与旧版本升级

更新便携发布文件时保留原桌面目录的 data，继续使用原解锁密码。0.2.0 不为旧库预生成恢复码：必须先正常解锁，再生成并另存。恢复码丢失可在正常解锁后更换；原密码遗失且从未建码时，无法绕过旧密码。恢复码、保险库和 DPAPI 材料使用带 journal 的文件组密码更新，重启可处理未完成提交；这不等于保证磁盘损坏后可恢复。

记忆同步面向实际 global_home/memory 下原生 Markdown。所选账号的快照保存在管理器加密库，用户选择来源并确认后合并到本机共享状态，也可直接打开而不同步。其他已打开的窗口可能看到合并，未提供官方云端账号记忆隔离。历史可精确回滚，可能移除该历史之后新增的受管文件，操作前会保存当前状态；请关闭相关 TRAE 窗口并核对路径。加密迁移包含当前原生记忆和已保存快照；导入原生记忆需要再次确认合并。真实记忆加载和跨机器项目映射效果仍需用户验收。

自定义标题栏提供拖动、双击最大化、最小化/还原/关闭及主题适配；多屏、DPI、任务栏与不同 Windows 外观仍按验收清单测试。
