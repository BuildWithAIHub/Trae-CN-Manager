# 0.2.2 功能覆盖与边界

本项目交付范围是 **TRAE CN 桌面端的账号、实例、签到和本地配置管理**。下面区分实现状态与验证方式；“已有实现”不等于已通过所有真实账号、官方接口和系统环境的验收。

状态含义：**已实现**表示存在可调用的业务流程和界面；**模拟测试**表示用合成数据、临时目录或模拟服务验证；**需真实验证**表示仍依赖官方账号、网络或 Windows 系统行为；**范围外/未实现**表示当前不提供。

## 账号与自动签到

| 能力 | 当前实现 | 验证与限制 |
| --- | --- | --- |
| 检测安装、默认资料与近期项目 | 已实现 | 路径发现、结构识别有自动化测试；不同安装版本需实际核对 |
| 授权后跨盘定位程序、资料、缓存、全局目录 | 已实现，可取消，可手动填写/浏览 | 默认限制约 120 秒/20 万个目录；保护目录、链接、无权限目录会跳过，部分结果不等于全盘完成 |
| 位置结果确认与移盘重找 | 已实现状态确认与缓存路径检测 | 当前状态确定后不重复提示；原位置失效先快速重新查找，路径/访问状态变化会重新提示；深度扫描需用户主动触发，完整移盘需实机验收 |
| 手机号官方登录 | 启动官方 TRAE 完成登录，再同步 | 需真实手机验证码与官方页面；管理器不代收短信 |
| 多账号保存、命名、备注、移除 | 已实现 | 保险库与账号流程有模拟测试；移除条目保留 TRAE 资料目录 |
| 一键启动所选账号实例、多个窗口并行 | 已实现独立 user-data-dir 与 extensions-dir 启动 | 两个以上真实账号的身份隔离、网页登录回调归属仍需用户验证 |
| 积分、用量、购买套餐和奖励权益 | 已实现读取官方权益返回值 | 默认 15 秒轮询，可调 5～300 秒/关闭/手动；签到后立即刷新，失败保留上次值及成功时间并标失败；不是推送，无法保证消费后瞬间更新 |
| 手动所选/全部签到 | 已实现，领取前查询、领取后复查 | 真实资格、奖励种类与服务可用性由官方决定 |
| 启动后自动签到 | 已实现为每次解锁后的自动操作，可关闭 | 已成功日期跳过；仅打开锁定界面不会解密账号签到 |
| 每日定时与登录后补跑 | 已实现，默认北京时间 09:00，可调整 | 优先 Windows 每日+登录任务及 StartWhenAvailable；创建失败降级为 HKCU 登录启动的独立后台进程 |
| 无计划任务权限时的降级 | 已实现，设置/诊断显示实际 task/startup 方式 | 实际注册结果取决于 Windows 环境；以本次检查报告和用户重启验收为准 |
| 窗口关闭后后台签到 | 已实现，显式启用 DPAPI 后台模式 | startup 进程退出 GUI 后仍运行，每 30 秒检查，普通失败重试间隔 15 分钟；取消后台后下一轮检查退出 |
| 关机、注销及重新登录 | 关机/未登录 Windows 不能运行，登录后补跑当天 | 不能补领历史日期；未伪造关机重启或新手机号实测通过 |
| 登录过期处理 | 显示失败/失效，提示官方登录后同步 | 不提供独立的自动 Token 刷新协议；可重读官方客户端更新后的同用户凭据 |
| 设备标识单独编辑/重置 | 未实现 | 自有迁移包可保留恢复所需官方上下文；不是机器码编辑器 |
| 云端 GitHub Actions 代替本机签到 | 范围外/未实现 | 本工具采用本机密码保险库与可选 Windows DPAPI 后台模式 |

## MCP、Skills、Rules 与数据

| 能力 | 当前实现 | 验证与限制 |
| --- | --- | --- |
| 默认实例/独立实例/项目 MCP | 已实现分开选取作用域 | 默认实例配置不会自动变成所有实例共用配置 |
| MCP 新建、编辑、删除、单项/批量/全部启停 | 已实现 | JSONC 读取、未知字段保留、原子写入、内容指纹竞争检查；批量选择校验失败不部分保存 |
| MCP 导入与实例间复制 | 已实现合并导入 | 重名不覆盖；支持 mcpServers 与兼容 servers 根对象 |
| MCP 本地文件夹搜索、HTTPS/raw/原生链接导入 | 已实现 | 搜索常见配置文件名并限制层级/数量；下载验证公开 HTTPS/跳转/IP/大小；原生链接须携带完整 config，单服务器需名称；不支持私库认证 |
| MCP JSON 导出 | 已实现，默认脱敏，可主动选择完整配置 | 普通 JSON 不加密；默认 args/env/headers 值脱敏，URL query/fragment 移除，导入前需补齐 |
| MCP stdio / HTTP / SSE 检测 | 已实现 initialize 与 tools/list，有超时 | 协议交互有模拟测试；真实本地服务需用户点击检测后验证；不调用实际工具 |
| 全局与项目 Skills | 已实现目录列表、元数据、编辑、启停、删除 | 全局在账号间共享；停用项移到 TRAE 扫描目录之外；停用后编辑保留原状态和作用域 |
| Skill 内文件与子目录管理 | 已实现树形查看、文本读写、新建目录/文件、启停、删除 | 文本限制 2 MB；二进制不以文本覆盖；主 SKILL.md 停用会停用整个技能，资源停用区在扫描目录之外 |
| Skills/Rules 选中或当前范围批量管理 | 已实现启停/删除与失败回滚 | 预检归属与冲突，保留修改前备份；系统权限/文件占用阻止恢复时明确报错，不承诺跨进程事务 |
| Skill 目录/Markdown/ZIP 导入与 ZIP 导出 | 已实现 | 目录穿越、符号链接、大小限制和重名冲突有测试；导入时不执行脚本 |
| Skill 公开 HTTPS Markdown/ZIP 导入 | 已实现 | 每次跳转检查公开 HTTPS；单 Markdown 不自动下载引用脚本/资源，界面说明主文件范围 |
| Skill 公开 GitHub 导入 | 已实现公开仓库、archive ZIP、tree 分支和子目录链接 | 指定子目录只安装该范围；斜杠分支按最长可用 ref 解析，最多 6 个边界；不支持私库认证与所有特殊布局 |
| 全局与项目 Rules | 已实现编辑、启停、删除，项目可含子目录 | TRAE 实际规则优先级及应用效果需在对应项目核对 |
| 自定义全局 Skills 存储目录与返回默认 | 已实现真实原生目录联接 | 迁移复制校验、拒绝重名覆盖、失败回滚；旧自定义目标保留，项目 Skills 不随之迁移；不接管既有非本工具联接 |
| 自动将外部 Skills 转为 TRAE 语义 | 未实现 | 检查 SKILL.md 结构并保存资源；不会保证第三方脚本兼容 |
| 本机密码保险库、修改密码、闲置锁定 | 已实现 | 加解密、错误密码、完整性和并发保护有测试；不承诺 Python 内存绝无残留 |
| 恢复码重设密码与数据目录入口 | 已实现，恢复码只生成时展示 | 保存公钥及加密恢复封装，不保存明文私钥/保险库密钥；旧库须先正常解锁生成，不能绕过遗失且无恢复码的旧密码 |
| 密码更新的一致性保护 | 已实现 vault/recovery/DPAPI 预计算及日志提交 | 伴随材料准备失败不替换旧组；提交失败回滚，重启处理未完成日志；磁盘权限/损坏仍可能需要人工恢复 |
| 加密账号+配置迁移 | 已实现独立迁移密码、合并账号 | 同一 TRAE 用户保留本机条目；跨机器可能需要官方重新验证 |
| 迁移配置恢复 | 已实现只写不存在文件，项目显式映射 | 未映射和冲突文件跳过；界面与后端分别验收 |
| 本地修改备份、恢复 | 已实现时间戳备份及恢复元数据 | 本地配置备份可能包含明文 API Key，不应公开上传 |
| 本机配置变更历史/回滚 | 已实现列出最近配置备份并选择回滚 | 恢复前再备份当前内容；仅限管理范围，恢复后需核对目标 TRAE 的实际加载 |
| 原生共享记忆与按账号加密快照 | 已实现保存来源、预览合并、直接打开 | 原生 memory 在本机用户窗口间共享；不是云端账号记忆隔离，其他窗口可能读到合并；[官方记忆说明](https://docs.trae.cn/ide_memories) |
| 记忆加密迁移与精确历史回滚 | 已实现当前原生记忆与已保存快照随加密包迁移 | 原生记忆导入需确认合并；回滚前再存当前快照，可移除历史之后新建的受管记忆文件；有数量/体积限制，需真实 TRAE 效果验收 |
| 日志、诊断、托盘、深浅主题、自定义标题栏 | 已实现 | 标题栏提供拖动、双击最大化与窗口按钮；DPI、多屏和系统缩放仍需实机验收；日志脱敏是尽力处理 |
| 本管理器 GitHub Release 检查 | 已实现，需填仓库 | 只检查最新发布并打开页面，不自动下载安装，也不自动适配新 TRAE |
| 自定义模型/Provider 切换 | 范围外/未实现 | 不将 AT-Switch 的产品能力算作本项目已覆盖 |
| 其他 IDE、其他地区 TRAE、完整 TraeWork 云端管理 | 范围外/未实现 | 本项目不能替代多产品账号管理器 |

## 公开项目调研对应

调研用于确认用户常见需求和已有产品范围。下表不表示复制源码、完整替代或性能胜出；也没有进行 GitHub 全站穷尽调查或“全球首创”检索。链接页面和许可证未来可能变化，维护者复用任何代码前仍须检查对应提交的授权。

| 参考项目 | 从公开说明识别的方向 | 本项目对应与明确差异 |
| --- | --- | --- |
| [star620/TraeTools](https://github.com/star620/TraeTools) | Trae Work 多账号、签到、用量 | 对应本项目的 TRAE CN 账号、签到、权益查询；未将 Work 全部特性移植 |
| [xhrxgr/Trae-Work-CN-Account-Manager](https://github.com/xhrxgr/Trae-Work-CN-Account-Manager) | 多账号切换、同时多开、机器码管理 | 对应独立实例启动和账号保存；独立机器码编辑/重置未实现 |
| [jlcodes99/cockpit-tools](https://github.com/jlcodes99/cockpit-tools) | 多种 AI IDE 的账号、额度与实例管理 | 仅参照账号/额度/实例的交互方向；其其他产品支持不在本项目范围 |
| [sciman-top/skills-manager](https://github.com/sciman-top/skills-manager) | Skills/MCP、本地迁移、便携管理 | 对应本项目的 TRAE 本地配置管理；不复制其完整 PowerShell 或多工具生态 |
| [atswitch/at-switch](https://github.com/atswitch/at-switch) | AI Agent Provider 与模型切换 | 本项目未实现该方向，也不计入多账号核心覆盖 |

本项目针对本次确认需求独立实现了：密码与 DPAPI 两种明确区分的运行模式、迁移账号去重合并、配置冲突跳过与项目映射、本机配置历史回滚、MCP 显式协议检测、ZIP/GitHub 导入约束、可追溯适配基线。这些是本交付的设计组合，不表示这些能力在其他项目中从未出现。

0.2.0 进一步加入授权定位与状态确认、文件级资源管理、原生目录联接迁移、定时积分轮询、恢复码与密码组更新、共享原生记忆的账号快照工作流。上述组合用于本项目的使用场景，不构成“拥有 GitHub 上所有功能”或“全球首创”的声明。最终测试统计和实际执行证据由本次自检报告记录；没有将真实全盘扫描、物理重启、所有付费套餐或真实记忆写入预先标记通过。
