# 下载、安装和发给朋友

普通用户下载 `TraeCNManager-0.2.4-Setup-x64.exe`，双击后选择安装文件夹并点击安装。默认仅安装到当前 Windows 用户目录，无需管理员权限；也可选择 E、F 等盘的可写文件夹。安装包已包含管理器的 Python 和 Qt 运行依赖。安装完成后使用桌面“Trae CN 管家”快捷方式。

**这个 Setup EXE 可以单独发送。便携文件夹中的 TraeCNManager.exe 不能单独发送。** 便携用户应发送完整 ZIP，让对方先完整解压，保留 `_internal` 后运行。MCP 自己需要的 Node/NPX/UVX 等第三方程序，以及 TRAE 本体，仍需按相应工具说明安装。

安装器先在所选目录旁的临时文件夹展开完整载荷，逐文件核验 SHA-256，再安装程序。升级失败时恢复本次已替换文件；不会读取、复制或删除 `data` 账号目录。目标含目录联接、符号链接或不相关的现有内容时会拒绝，避免误写入。目录已有本工具时可以原位升级；先完全退出旧版界面和独立后台签到进程，避免 Windows 锁定正在运行的文件。

默认账号目录为安装文件夹的 `data`。需要搬迁账号时使用软件内的加密迁移备份；给朋友发送软件不要发送自己的 data。安装到新文件夹属于新的空白数据目录；升级已有便携版本时选择其原文件夹，继续使用原密码和原账号。

打不开时先核对下载的是 Setup 完整安装包或完整便携 ZIP，系统为 Windows 10/11 x64。保留出错文字和软件版本，反馈时不要发送账号库或凭据。项目尚未购买代码签名证书，Windows 可能显示未知发布者；核对发布页和文件哈希后由使用者决定是否运行。

开发者无界面安装验收：

```powershell
.\TraeCNManager-0.2.4-Setup-x64.exe --silent --no-shortcut --install-dir "E:\测试目录\TraeCNManager" --report "E:\测试目录\安装结果.json"
.\TraeCNManager\TraeCNManager.exe --self-test
```

静默安装不会自动打开管理器。普通界面中可选择创建快捷方式及完成后打开。Qt 动态依赖保持独立文件，第三方许可证位于安装目录的 licenses 和 THIRD_PARTY_NOTICES.md。
