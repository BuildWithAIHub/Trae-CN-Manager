# 常用操作

账号页：在顶部搜索账号。“添加账号”可检测本机账号或新建独立实例。选中账号后，可打开、签到或刷新积分；同步登录、编辑备注、记忆与全部账号操作放在“更多”。

按住 Ctrl 点击可选择多个账号；Shift 可连续选择。绿色“✓ 今日已签到”表示官方已确认当天签到，按钮会禁用。在 TRAE 内签到后，下一次官方状态刷新也会更新标记。批量结果分别显示本次成功、此前已签、未开放与失败。

MCP 页：先选配置范围，再搜索或筛选服务。“添加服务”用于新建，“导入”支持文件、网址和配置文件夹。选中服务后，可编辑、启停和检测连接；导出、复制和批量管理放在“更多”。

Skills 和 Rules：列表只显示一句用途，完整内容在编辑窗口中保留。导入或保存后会自动更新用途；选中查看，双击编辑。

选中一个 Skill 或 Rule，在用途右侧点“翻译”，选择中文或英文，也可“显示原文”。首次使用会询问是否同意发送这一句用途；原文件不会改写。翻译设置可切换服务或撤销授权，密钥留空保留已有值；勾选清除才删除。

Skills 顶部“全部翻译”处理当前配置范围中的所有用途，包括被搜索隐藏的条目；可选择中文、英文或恢复全部原文。开始前显示数量和接收服务，确认后逐项翻译，进度窗口可取消。取消会保留已完成的显示结果，不更改原文件。额度用尽或部分失败会说明完成与未完成数量。

新建、编辑、提示、文件选择及安装窗口都使用统一顶部样式。窗口可拖动；右上角关闭或 Esc 取消当前弹窗。安装过程中需等待操作完成。

搜索或筛选后，“所选”仅处理当前可见的选中条目。“全部”会明确显示范围和数量，删除前需确认。
