# 发布与分享

给朋友发送完整 Setup EXE 即可；便携版需要发送并完整解压整个 Windows ZIP。不要发送自己使用目录里的 `data`、实例目录、账号备份或恢复码。对方首次启动应创建自己的保险库。

GitHub 仓库只保存源码、测试、图标、许可证和说明。安装包放在 Release，安装和便携包都由干净的构建目录生成；不能直接压缩日常使用中的安装目录。

发布前检查文件白名单、压缩包内容、个人路径与凭据，并核对 SHA-256。不要上传 `.env`、数据库、日志、Token、Windows 后台密钥、真实 MCP 配置或私人记忆。测试使用的账号与配置必须为虚构内容。

提交作者使用 GitHub 的 noreply 邮箱。新建仓库不会继承开发目录或其他项目的 Git 历史。源码可以公开审阅；Release 中的自检报告说明实际测试范围和仍需人工验证的项目。
