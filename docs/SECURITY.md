# 0.2.2 安全与数据处理

本工具需要读取用户主动管理的 TRAE 本地登录状态，并向官方接口执行查询或签到。它不是操作系统沙箱，也无法保护已经被同一 Windows 用户下恶意程序或管理员控制的会话。

## 数据存放和密码

默认数据位于管理器程序旁的 `data/`；使用 `--data-dir` 时以指定位置为准。

| 数据 | 用途 | 保护与注意事项 |
| --- | --- | --- |
| accounts.vault | 账号登录快照、设置、项目列表、应用日志、账号记忆快照与记忆历史 | 密码派生密钥加密；不是明文账号 JSON |
| recovery.json | 恢复公钥、临时公钥及加密的保险库恢复材料 | 不保存恢复私钥、恢复码或明文保险库密钥；与对应账号库一起保管 |
| background.key | 仅显式启用后台签到时存在 | 计划任务与 HKCU 降级进程共用的当前用户 DPAPI 解密材料，不是跨机器迁移凭证 |
| locations.json | 扫描授权、检测结果、手动路径及确认状态 | 路径元数据不加密，不保存账号凭据或项目正文 |
| .rotation.journal | 中断密码更新时恢复文件组的一致性 | 保存原有加密/DPAPI 文件副本与提交状态，不保存明文密码或新密钥；正常完成后删除 |
| instances/ | 管理器创建的独立 TRAE 资料目录 | 遵循 TRAE 本身的存储方式，不因保险库上锁就全部变成管理器加密文件 |
| config-backups/ | MCP/Skills/Rules 修改与删除前备份 | 可能含明文 MCP 环境变量、请求头或私人技能，不应公开 |
| 实际全局目录/memory/ | TRAE 原生共享记忆文件 | 遵循 TRAE 的本地存储方式，不因管理器锁定变成密文；同用户其他 TRAE 窗口可能读取 |
| 用户导出的 .tcmbackup | 账号、配置、当前原生记忆及已保存记忆快照迁移包 | 独立迁移密码加密，仍按敏感备份保管 |
| 用户导出的 JSON / Skill ZIP / 日志 | 配置交换或诊断 | 不提供通用文件加密；需逐个核对敏感内容与分享权限 |

本机保险库与迁移包使用 PBKDF2-HMAC-SHA256 派生 256 位密钥，当前迭代次数 600,000，随机 salt；AES-256-GCM 使用随机 nonce 并校验完整性。密码至少 8 个字符，应选择更难猜的独立密码。修改本机密码不会改变已经导出的迁移包密码。

锁定时程序清除自己持有的可变密钥缓冲区引用并隐藏账号界面；Python、Qt 和密码学库可能产生其他内存副本，因此不承诺所有进程内存被可靠擦除。

恢复码是随机生成的 X25519 私钥编码，具有高熵，不是用户自选提示问题。管理器用对应公钥、临时密钥交换、HKDF 和 AES-GCM 封装保险库解密材料；磁盘只保留公钥和加密封装。完整恢复码只在生成时展示，程序不能从 recovery.json 再显示它，也不能查出原密码。复制到剪贴板或由用户另存的恢复码需要用户自行保护；**掌握恢复码及相应账号库/恢复文件即可访问账号数据并重设密码**。

登录页“忘记密码”允许验证已生成的恢复码并重设至少 8 字符的新密码。生成新码会替换旧公钥，使旧码失效；修改密码会用原恢复公钥重新封装新的解密材料。旧版升级保留原 `data/` 和原密码，**不会预先生成恢复码**。旧库必须先正常解锁才能建立恢复信息；旧密码遗失且事前没有恢复码时，本功能无法绕过密码。可用密码已知的迁移备份导入新库；数据目录入口只是帮助找到文件，不是解密途径。后台 DPAPI 是独立的已授权本机运行能力，不当作通用忘记密码恢复码。

修改或重设密码会预计算 accounts.vault、recovery.json 和已启用的 background.key，再以日志记录的文件组提交。准备失败保持原文件组，提交失败回滚；重启时恢复未完成提交，避免账号库与恢复/后台材料各用不同密钥。恢复仍依赖磁盘可写和文件完整；出现恢复未完成错误时应保留整个 data，不要手动删除 journal 或混用不同日期的文件。跨机器迁移优先使用 `.tcmbackup`。

## 目录定位授权

首次解锁先快速核验已确认位置、运行程序、系统登记和常见目录；找到后无需全盘扫描。仅在用户主动选择深度扫描时询问是否允许跨盘读取目录名称。授权选择与位置结果“确定”分别保存；点击“确定”只抑制当前状态的重复提示。旧路径失效时先快速重找，位置或访问状态变化后重新提示；深度扫描始终需要用户主动触发，也可手动输入或浏览路径。程序不自动取得管理员或操作系统拒绝的访问权限。

扫描限制约 120 秒/20 万个目录，可取消，跳过系统保护目录、目录链接和无权限目录。达到限制、取消或访问被拒绝会报告部分结果，不能将其称为“全盘已经完整读取”。扫描以位置和产品结构识别为目的，不遍历读取用户项目正文；账号同步随后按明确的账号流程读取相应官方本地登录状态。授权与路径元数据保存在当前 data 中，分享文件前也应检查个人路径。

## 可选后台运行模式

默认不启用。只有用户勾选并保存后台签到时，程序才存储 DPAPI 保护的密钥材料，优先创建自己的 Windows 计划任务。任务采用当前用户 `InteractiveToken`，不需要保存 Windows 登录密码，也不会申请管理员级别。

计划任务创建失败时，自动改用 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 下本工具专用的 `TraeCNManager-*-Background` 启动项，并运行隐藏的独立 `--background` 进程。它只在当前用户会话中运行，设置/诊断区分实际 `task`、`startup`、未启用或待确认状态。不会把启动项注册成功称为计划任务注册成功。

**退出管理器 GUI 不会结束已授权的独立后台进程**。降级进程每 30 秒重新读取计划时间和开关；普通签到失败的重试间隔为 15 分钟，同日已成功条目跳过。取消并保存后台开关后，空闲进程在下一次检查（约 30 秒内）退出；已经进行中的操作需先结束。关机/退出 Windows 会话后无法继续执行，下一次登录由专用启动项重新启动并尝试当天签到。

启用意味着你允许该 Windows 用户会话在未输入管理器密码时执行后台签到；界面锁定与后台授权是两个不同控制。锁屏不等于退出 Windows 会话。DPAPI 用于绑定本机用户环境，无法抵御已取得当前用户权限或系统管理员权限的程序。关闭后台签到会移除本工具任务、专用后台启动项与 background.key；另一个“启动管家 GUI”开关独立管理。操作系统或云盘中已有的历史备份不由此自动清除。

每日任务、登录后补跑和手动签到共用本机网络操作锁与当天成功记录。关机期间无法执行，也不能把过去日期的签到当作今天补领成功。

## 官方账号与接口

手机号、验证码及人机验证在官方 TRAE 登录流程完成。管理器不提供短信代收、验证码绕过或独立账号注册功能。当前实现不包含独立自动 Token 刷新协议；官方客户端更新登录状态后同步，或者签到前重读对应用户的本地状态。

TRAE 原生本地容器的兼容读取不是本工具保险库的安全边界。恢复登录状态只写入管理器自己创建并带有归属标记的实例目录，不把自有迁移数据覆盖到任意官方安装或已有默认账号。跨设备使用是否需要重新验证由官方决定。

程序通过官方接口查询签到状态、领取并复查。未复查成功、未开放、认证失败或网络失败都不应记为成功。官方账号策略、设备限制、奖励和 API 未来均可能变化；[兼容性文档](COMPATIBILITY.md)说明验证基线。

## 配置导入与 MCP 执行

读取、编辑、保存和导入配置不会自动运行 MCP。**连接检测会实际启动配置中的命令或访问其 URL**，并执行 MCP initialize 和 tools/list；stdio 命令可能由 NPX/UVX 下载代码。请只检测自己认可的配置。检测设置超时并尽力结束自己启动的进程树；不应把它视为对任意不可信程序的隔离运行环境。

配置写入使用临时文件、原子替换与内容指纹检查，修改前留备份。它不与 TRAE 共享跨进程事务，因此建议修改重要配置、恢复或迁移前关闭目标 TRAE，并在发现竞争修改时刷新。保存保留未知 JSON 字段，但不保留 JSONC 注释与原排版。

MCP 默认导出将 args、env、headers 值脱敏并移除 URL query/fragment；未知自定义字段和其他文本仍需要人工检查。选择完整导出时可包含有效凭据。脱敏导出需要自行补齐配置才能实际运行。

Skill ZIP 导入限制压缩包大小、解压总大小、文件数和单次技能数量；拒绝路径穿越、绝对路径、Windows 设备名、符号链接及重名覆盖。目录导入也检查链接和总量。导入过程中不执行脚本；技能随后被 TRAE 使用时仍可能引导执行其自带脚本，应先审阅来源。

公开 GitHub 仓库导入仅允许 HTTPS github.com 与受限下载跳转域名。tree 链接最多尝试 6 个分支边界，只有 404 才继续解析；指定子目录时，仅从该目录挑选技能，不安装同仓库其他目录的技能。整个 ZIP 仍执行路径和体积校验。

0.2.0 另支持公开 HTTPS 配置/ZIP/Markdown 文件（含 GitHub raw/blob 配置）下载，每次跳转重新检查协议、主机和解析 IP，拒绝内嵌凭据及私有/回环地址，忽略环境代理并限制大小/时间。MCP 的 SSE 服务流不能作为配置 JSON 导入；原生 trae-cn/trae 的 mcp-import 链接只解析 JSON/base64 配置，不启动链接中的程序。单独 Markdown 导入不递归下载引用资源。上述约束不等于恶意内容检测或操作系统级网络隔离；私有仓库认证、HTTP 文件下载和自动运行安装脚本仍不支持。用户配置的本地 MCP 可以合法访问 localhost。

逐项停用 Skills/Rules 会移到原生扫描目录之外；技能内资源使用 `.trae-manager-disabled-skill-entries/<技能>/…`。批量操作先检查归属与冲突，失败时尝试还原本次修改；系统阻止回滚时明确失败并保留备份。自定义 Skills 存储采用真实 Windows junction，禁止将子目录链接当作受管条目删除，也不会递归删除联接的旧目标。只解除本工具创建且记录匹配的原生联接；既有非本工具联接不接管。迁移前备份、拒绝同名覆盖、校验复制，失败恢复原入口；返回默认保留原自定义目录。

## 积分与共享记忆

积分默认每 15 秒轮询，可调 5～300 秒或关闭，签到后立即请求刷新；失败保留上次成功值并标明时间和失败。它不是服务端推送，也不保证消费后零延迟。购买套餐、签到奖励等以官方接口实际返回为准，缺失或失效状态不可当作有效余额。

按[官方记忆文档](https://docs.trae.cn/ide_memories)，原生用户记忆和项目记忆位于本机全局目录的 memory 下。账号快照只是管理器保存在保险库中的命名副本，原生文件并非按账号自动隔离。同步先选来源并确认预览，合并保留已有内容并去重；其他已打开 TRAE 窗口也可能读到合并结果。“不同步，直接打开”继续使用当前共享状态，不会还原另一份账号专属原生目录。

合并前版本进入加密历史。精确回滚会恢复该快照范围，并可能删除之后新建的受管原生记忆文件；操作前再保存当前状态。文件有类型、路径、大小、数量和并发检查；它不是与 TRAE 共享的跨进程事务，重要记忆操作应先关闭相关窗口并保留迁移备份。

## 迁移、日志与源码发布

### 可选在线翻译

翻译只在用户点选中英方向后执行，只发送当前一句用途，不发送文件、路径、账号或 MCP 凭据。默认 MyMemory 的[服务条款](https://mymemory.translated.net/terms-and-conditions)说明提交文字可能长期保存并交由外部翻译伙伴处理；首次请求需明确同意，可在翻译设置撤销。敏感用途可保留原文，或选择自己信任的 LibreTranslate 服务。

“全部翻译”会在发送前单独说明当前范围、条目数量和接收服务，需再次确认。逐项请求仍然只含一句用途，不上传文件正文或压缩包；同一用途和方向复用结果，取消后停止后续请求，已发出的单次请求等待超时或响应。服务限流或当日额度用尽时停止批次，不轮换身份或绕过限额。

MyMemory 的[接口规格](https://mymemory.translated.net/doc/spec.php)限定每段 500 UTF-8 字节，[匿名额度](https://mymemory.translated.net/doc/usagelimits.php)为每日 5,000 字符。超额或服务错误会保留原文，不自动换第三方服务。译文仅影响显示；配置、密钥与最多 200 条译文缓存保存在保险库加密文档内，锁定后清除界面译文。更改翻译服务需重新同意，进行中的请求不会在撤销或重新锁定后显示结果。自定义公网服务须使用 HTTPS，本机服务允许 HTTP；拒绝嵌入账号、查询参数和片段的地址。

加密迁移导入合并账号，对同一 TRAE 用户保留本机条目；不照搬备份内后台计划设置或 Windows DPAPI 密钥。配置恢复只写不存在文件，项目目标必须在本机显式映射，路径穿越和不允许的资源类型会被拒绝。当前原生记忆与已保存的账号快照随加密备份迁移；原生记忆导入后须由用户确认合并，不自动照搬旧机器共享状态。

本机配置历史回滚与迁移恢复不同：用户选择历史记录后可以替换管理范围内的当前文件，替换前会再备份当前内容。应核对历史的原路径和时间，再决定是否回滚。

应用日志隐藏常见凭据格式，界面不会有意显示完整登录 Token。任何基于模式的脱敏都不等于完整秘密识别；导出的日志、个人路径、账号名称和第三方错误信息需在公开前自行核对。

源码发布不附带个人账号、data 或真实本机配置。不要公开保险库、recovery.json、恢复码、background.key、rotation journal、完整 MCP 导出、自有实例目录、私人记忆或带敏感资源的技能包。发现漏洞时，先通过仓库维护者提供的私下渠道发送最小复现，勿把有效凭据和真实账号数据放进公开 Issue。维护者尚未配置私下联系渠道时，先发布不含利用细节和个人数据的联络请求。
