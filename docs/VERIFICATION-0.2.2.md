# 0.2.2 界面验收记录

日期：2026-10-24（北京时间）。本版调整账号、MCP、Skills/Rules 说明与窗口样式；账号认证、签到协议和数据加密格式保持原实现。TRAE 3.4.7 的真实连接记录见 [0.2.1 实机验收](VERIFICATION-0.2.1.md)。

- 账号与 MCP 页改为搜索、状态筛选、添加和菜单；单项操作随选择显示。记忆和批量动作收进菜单，全部操作明确标明范围。
- 积分自动刷新保持搜索、筛选和选择；账号 ID、备注放入详情。MCP 列表只显示名称、状态、类型，连接结果使用简短中文提示。
- 修正筛选后 Ctrl+A 选中隐藏条目的问题；“所选”仅处理可见选择，显式“全部”仍处理完整范围。新增 8 项工作台交互测试通过。
- Skills/Rules 列表与详情使用一句用途摘要，支持无 YAML 描述的规则正文，保留完整原文；新建、编辑、导入和刷新后重新计算。8 项描述与文件保留测试通过。
- 编辑、密码、输入、恢复、确认、提示、文件选择及 Qt 内部覆盖确认窗口使用同一主题标题栏。文件选择为中文界面；深浅主题一致。
- 修正 Qt 文件选择器关闭按钮的临时 wrapper 问题。最终 13 项弹窗测试通过，覆盖 Enter/Esc、默认取消、右上角关闭、长提示展开和重复打开。
- 实际 Windows 检查确认编辑器、提示、文件选择器的 WS_CAPTION 位均未设置，自定义标题栏可见，且可通过自定义关闭按钮退出。
- 完整安装器主窗、提示和目录选择器也使用自绘深绿顶部；保留拖动、最小化、忙时退出保护、进度与静默安装。安装器独立 8 项 GUI 测试通过。

完整回归记录为 **297 项通过、1 项跳过**。跳过项在混合 Qt/Tk 测试进程中无法初始化本机 Tcl；安装器单独测试及实际安装包启动会另行核验。最终弹窗修复后的专项记录为 **28 项通过、1 项相同环境跳过**，其中弹窗 13 项及描述 8 项均通过。上述数字包含重叠用例，不相加作为独立测试总数。

打包后还需通过 Setup EXE 单文件安装、程序内置自检、深浅主题弹窗 smoke、Qt 中文翻译文件存在和数据保留升级检查；最终结果记录在交付文件夹的自检报告和验证 JSON。预览使用合成账号、配置及描述，不包含真实凭据。此轮无需修改本机 TRAE 的记忆、MCP、Skills、Rules 或日常账号库。
